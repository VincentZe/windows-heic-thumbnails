Fast Windows HEIC / HEIF / DNG thumbnails (64-bit Windows 10/11)

1. Extract the complete ZIP on the target PC. Keep all four DLLs together.
2. In the extracted folder, open PowerShell and run:
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
3. Restart File Explorer if it still shows cached blank thumbnails.
The installer runs the COM interface check before changing Windows registration.

To check the packaged DLL's COM interfaces before installation:
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\verify-com.ps1
BUILDINFO.txt contains the source commit and SHA256 of the packaged DLL.

This installs for the current Windows user only; administrator access, Visual Studio
and vcpkg are not needed. Requires the Microsoft Visual C++ 2015-2022 x64 runtime:
https://aka.ms/vs/17/release/vc_redist.x64.exe

To restore the previous thumbnail providers, run in the extracted folder:
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Uninstall

The installed DLLs remain in %LOCALAPPDATA%\FastImageThumbnails after uninstall;
do not delete them while the extension is registered. Existing thumbnails cached by
Explorer may remain visible after uninstall.
