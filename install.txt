
Build x64 Release, then create a portable ZIP on the build PC:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\package.ps1

Copy the ZIP from artifacts\ to a 64-bit Windows 10/11 PC, extract it, and run:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1

On the build PC, direct installation from the source checkout also works:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\install.ps1

For building or packaging, vcpkg must be on PATH, VCPKG_ROOT must be set, or
-VcpkgRoot must be supplied. The target PC does not need vcpkg or Visual Studio.
The script installs four DLLs under %LOCALAPPDATA%\FastImageThumbnails and registers
the thumbnail provider for .heic, .heif and .dng for the current user only.
It remembers the previous thumbnail provider for each extension.

To restore the previous thumbnail associations:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Uninstall

Use scripts\install.ps1 -Uninstall instead when running from a source checkout.

The DLL files remain in the install directory after unregistering; remove them manually
once the shell has released the handler. Previously cached thumbnails may persist.
